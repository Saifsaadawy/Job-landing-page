# صفحة إعلان وظيفة + لوحة تحكم (Job Landing Page + Admin Panel)

مشروع Flask بسيط: صفحة هبوط عربية (RTL) للإعلان عن وظيفة، مع لوحة تحكم محمية
لتعديل بيانات الصفحة — وأهمها رابط جروب واتساب — بدون فتح أي كود.

## الفكرة باختصار

- **`/`** — الصفحة الرئيسية (Landing Page) التي يشاهدها المتقدمون للوظيفة.
- **`/admin`** — لوحة التحكم (تتطلب تسجيل دخول).
- **`/admin/login`** — صفحة تسجيل الدخول.
- **`/admin/logout`** — تسجيل الخروج.

كل البيانات (اسم الشركة، الوظيفة، المكان، المواعيد، الإجازات، المميزات،
المتطلبات، ورابط واتساب) مخزنة في قاعدة بيانات SQLite، ويتم تحميلها ديناميكيًا
في الصفحة الرئيسية. أي تعديل من لوحة التحكم ينعكس فورًا على كل أزرار واتساب
في الصفحة.

## التشغيل محليًا (Windows)

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ثم افتح:

- الصفحة الرئيسية: http://127.0.0.1:5000
- لوحة التحكم: http://127.0.0.1:5000/admin

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

عند أول تشغيل، يقوم `app.py` تلقائيًا بإنشاء `database.db` وجدول `settings`،
ويملأه بقيم افتراضية (يمكنك تغييرها فورًا من لوحة التحكم).

## بيانات الدخول الافتراضية (⚠️ للتجربة فقط)

```
اسم المستخدم: admin
كلمة المرور:  admin123
```

**هذه بيانات تجريبية يجب تغييرها قبل نشر المشروع Online.** كلمة المرور
مخزّنة كـ Hash في الذاكرة (وليست نصًا صريحًا)، ولا تظهر أبدًا داخل أي ملف
HTML. لتغييرها، اضبط متغيرات البيئة التالية قبل تشغيل المشروع:

```bash
# Windows (PowerShell)
$env:ADMIN_USERNAME="اسم_مستخدم_جديد"
$env:ADMIN_PASSWORD="كلمة_مرور_قوية"
$env:SECRET_KEY="سلسلة عشوائية طويلة وسرية"

# macOS / Linux
export ADMIN_USERNAME="اسم_مستخدم_جديد"
export ADMIN_PASSWORD="كلمة_مرور_قوية"
export SECRET_KEY="سلسلة عشوائية طويلة وسرية"
```

`SECRET_KEY` يُستخدم لتوقيع الـ Session (تسجيل الدخول)، فيجب أن يكون قيمة
عشوائية وسرية في أي بيئة إنتاج (Production).

## كيف يعمل تحديث رابط واتساب

1. الأدمن يدخل `/admin` ويسجّل الدخول.
2. يغيّر قيمة "لينك جروب واتساب".
3. يضغط "💾 حفظ التعديلات" — يتم إرسال الطلب عبر AJAX إلى `/admin/update`.
4. السيرفر يتحقق أن الرابط غير فارغ ويبدأ بـ `https://`، ثم يحفظه في جدول
   `settings` بقاعدة البيانات.
5. أي زيارة جديدة للصفحة الرئيسية `/` تقرأ الرابط الجديد من قاعدة البيانات
   مباشرة، فتتحدث كل أزرار واتساب تلقائيًا — بدون أي تعديل في الكود.

## اختبار السيناريو الكامل

1. افتح `/` وشاهد الصفحة الرئيسية.
2. اضغط زر واتساب — يفتح الرابط الحالي المخزّن في قاعدة البيانات.
3. افتح `/admin` وسجّل الدخول ببيانات الأدمن.
4. غيّر "لينك جروب واتساب" إلى رابط جديد.
5. اضغط "حفظ التعديلات" — يجب أن تظهر رسالة "تم حفظ التعديلات بنجاح ✅".
6. افتح الصفحة الرئيسية مرة أخرى (أو حدّثها).
7. اضغط زر واتساب — يجب أن يفتح الرابط الجديد.

## النشر Online (Production)

المشروع بسيط بما يكفي للعمل على أي خدمة تدعم Python/Flask. قبل النشر:

1. **غيّر بيانات الأدمن و `SECRET_KEY`** كما هو موضح أعلاه (كمتغيرات بيئة على
   الخادم، وليس داخل الكود).
2. **أوقف وضع Debug**: في `app.py`، شغّل التطبيق بدون `debug=True`، أو دع
   خدمة الاستضافة تشغّله عبر WSGI server مثل `gunicorn`:
   ```bash
   pip install gunicorn
   gunicorn app:app
   ```
3. **قاعدة البيانات**: SQLite مناسب تمامًا لمشروع بسيط بعدد زوار متوسط.
   إذا توقعت عدد كبير جدًا من المستخدمين المتزامنين أو احتجت نسخًا احتياطية
   واستضافة موزّعة، يُفضّل الانتقال إلى PostgreSQL (عبر مكتبة مثل
   `psycopg2` وتعديل بسيط في طبقة الاتصال بقاعدة البيانات في `app.py`).

### Render

1. ارفع المشروع على GitHub.
2. أنشئ "New Web Service" على Render واربطه بالمستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. أضف متغيرات البيئة `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SECRET_KEY` من
   إعدادات "Environment" في Render.
6. ملاحظة: تخزين Render للملفات مؤقت في الخطة المجانية، فقد يُعاد ضبط
   `database.db` عند إعادة النشر. لبيانات دائمة استخدم Render Disk أو
   انتقل إلى قاعدة بيانات خارجية (مثل PostgreSQL على Render).

### Railway

1. ارفع المشروع على GitHub واربطه بمشروع جديد على Railway.
2. Railway يكتشف Flask تلقائيًا؛ تأكد أن Start Command هو `gunicorn app:app`.
3. أضف نفس متغيرات البيئة من "Variables".
4. لضمان بقاء `database.db`، أضف Volume دائم واربطه بمسار المشروع.

### PythonAnywhere

1. ارفع ملفات المشروع (أو استنسخ المستودع) داخل حسابك.
2. من تبويب "Web"، أنشئ Web App جديد واختر Flask، ثم وجّه WSGI file لاستدعاء
   `app` من `app.py`.
3. أضف متغيرات البيئة من تبويب "Web" (أو داخل ملف WSGI عبر `os.environ`).
4. أعد تحميل التطبيق (Reload) بعد أي تعديل.

## التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (RTL, Responsive)
- **Backend**: Python + Flask + Jinja2
- **Database**: SQLite (جدول واحد `settings` بنظام key/value)
- **Auth**: Flask Session + Werkzeug password hashing (بدون أي مكتبات
  Frontend framework ثقيلة)
